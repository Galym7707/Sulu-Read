# Выжимка

## Ядро технологии

Технология описана как «Очки для ушей» — патентованная цифровая обработка речи:

- звуки речи сначала предъявляются в замедленном темпе;
- темп постепенно ускоряется по мере адаптации мозга;
- целевой дефицит — обработка согласных звуков.

Формулировка источника: «мозг детей с нарушением развития речи не успевает корректно
обрабатывать входящие звуковые сигналы в темпе нормальной человеческой речи».

## Структура тренировки

Описана как «фитнес для мозга»: игровые упражнения с прогрессивно растущей сложностью.
Объём, необходимый для результата: «40-60 часов игр-занятий».
