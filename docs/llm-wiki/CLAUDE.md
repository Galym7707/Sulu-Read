# Sulu Read — LLM Wiki (метод Карпатого)

Внешняя долговременная память проекта Sulu Read по теме «чтение при дислексии».
Человек владеет `raw/`, LLM владеет `wiki/`.

## Purpose

Собрать в одном месте всё, что известно про коррекцию дислексии из предоставленных
первоисточников (брошюра по методу Дейвиса, davismethod.com, dyslexiadar.com, fastfword.com),
и спроектировать на этой основе новый режим чтения для приложения Sulu Read.
Потребитель vault: разработчик Sulu Read и LLM-агент, который пишет код приложения.

## Data Model

- Первоисточник = один файл в `raw/sources/<slug>.md`. Формат фиксации: markdown,
  шапка `<!-- READ-ONLY -->`, затем происхождение (URL/файл, дата получения, способ получения),
  затем текст или извлечённая выжимка. Если это выжимка, а не полный текст — это указано явно.
- Имя источника для маркеров цитирования = `source_name` из соответствующего
  `wiki/sources/<slug>.md`.
- Уровни разбора содержимого: **механизм** (как устроена дислексия) → **техника**
  (что делает человек) → **параметр** (числа, тайминги, пороги) → **ограничение**
  (чего делать нельзя).

## Taxonomy

Только эти метки:

- `dezorientaciya` — дезориентация, порог замешательства, триггеры путаницы
- `vizualnoe-myshlenie` — образное/невербальное мышление, картинки вместо слов
- `tempo-obrabotki` — скорость обработки звука и символов, тайминги
- `uprazhnenie-chteniya` — конкретные упражнения чтения и их шаги
- `ui-ogranicheniya` — требования и ограничения интерфейса приложения
- `izmerenie-effekta` — измеримые результаты, выборки, цифры
- `eticheskie-granicy` — что нельзя обещать пользователю

Категории `other` / `misc` запрещены.

## Page Types

`source_note`, `cluster_page`, `question_page`, `concept_page`, `content_idea` —
контракты в `templates/page-contracts.md`.

## RAG

Поиск по vault: `python docs/llm-wiki/rag_query.py "запрос"` — BM25 по markdown-чанкам
vault, только стандартная библиотека, без индекса на диске. Возвращает файл + секцию +
фрагмент, чтобы дальше читать страницу целиком. Это retrieval для ответов по vault,
а не замена чтению `wiki/index.md`.

## Never Do

1. Не обещать лечение, исцеление или диагностику дислексии — ни в vault, ни в UI приложения.
   Sulu Read даёт поддержку чтения, а не терапию.
2. Не выдавать маркетинговые числа из брошюр («+4 класса за 5 дней») за результат,
   ожидаемый от приложения.
3. Не переносить в приложение офлайн-инструменты метода Дейвиса (пластилин, лицензированный
   специалист) как будто их можно заменить экраном — можно ссылаться, нельзя подменять.
4. Не редактировать `raw/`, кроме добавления новых файлов-источников.
5. Не блокировать пользователя на слове: любая эскалация подсказок обязана иметь выход,
   иначе интерфейс сам становится источником замешательства.
