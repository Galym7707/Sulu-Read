# dyslexiadar.com — раздел «Статьи»

## Profile

Русскоязычный перевод материалов Davis Dyslexia Association International, 13 статей
в разделе. Прочитано и заингещено 5 статей (механизм дислексии, порог замешательства,
два упражнения чтения, пунктуация в образах, исследование распознавания слов).
Это самый содержательный источник набора: единственный, который описывает упражнения
пошагово и даёт цифры исследования.

## Принято / Отклонено

**Принято в работу:** механика Spell-Reading (буквы по названиям), Sweep-Sweep-Spell и её
требование скорости, остановка на пунктуации с проверкой образа, порог замешательства как
ограничение на количество подсказок, метрика «список слов, порог точности».

**Отклонено:** «Освоение символов по методу Дейвиса®» с пластилином — офлайн-техника,
требующая лицензированного фасилитатора, экраном не заменяется (см. Never Do #3 манифеста).
Тезисы о «даре» и «основе гениальности» — мировоззренческая рамка, в UI не переносим как
утверждения.

## Fact-check

Цифры исследования (86 учеников, 100 слов, порог 80%, Манна-Уитни) взяты из статьи как есть
и НЕ проверялись по первичной публикации. Это данные разработчика метода о собственном
методе — конфликт интересов; уверенность в кластере с цифрами понижена до medium.
