# fastfword.com — «Развитие речи» (Fast ForWord)

## Profile

Коммерческая страница провайдера Fast ForWord. Единственный источник набора, который говорит
о **темпе обработки звука**, а не о символах и образах. Заказчик прямо просил рассмотреть
применение этой технологии («also consider applying fastword technology here»).

## Core Concepts

| Концепт | Суть | Куда внедрено |
|---|---|---|
| Акустическая модификация речи | «Очки для ушей»: звуки предъявляются замедленно, темп растёт по мере адаптации | [[../clusters/temporalnaya-obrabotka-fastforword\|Темпоральная обработка]] |
| Дефицит темпа | «мозг детей с нарушением развития речи не успевает корректно обрабатывать входящие звуковые сигналы в темпе нормальной человеческой речи» | [[../clusters/temporalnaya-obrabotka-fastforword\|Темпоральная обработка]] |
| Целевые звуки — согласные | Основная нагрузка на различение согласных | [[../clusters/temporalnaya-obrabotka-fastforword\|Темпоральная обработка]] |
| Адаптивная сложность | «фитнес для мозга», игровые упражнения с растущей сложностью | [[../clusters/temporalnaya-obrabotka-fastforword\|Темпоральная обработка]] |
| Объём тренировки | «40-60 часов игр-занятий», результат за «3-4 месяца» | [[../clusters/temporalnaya-obrabotka-fastforword\|Темпоральная обработка]] |

## Принято / Отклонено

**Принято:** принцип «замедлить, затем ускорять по мере адаптации» — реализуемо на штатном
Android TTS через скорость речи; принцип адаптивной сложности; ориентир на порядок величины
объёма практики (десятки часов, а не одно занятие).

**Отклонено:** «Пожизненный результат», «откатов не бывает» (Never Do #2). Патентованная
обработка сигнала (растяжение и усиление отдельных фонем) — реализовать честно на TTS нельзя;
в продукте это только регулировка скорости и пауз, и так это и должно называться.

## Fact-check

Числа «40-60 часов», «3-4 месяца» приведены без описания измерения — приняты как ориентир
провайдера, не как доказанный результат. Уверенность medium.
