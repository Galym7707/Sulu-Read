# Брошюра «Коррекция дислексии по методу Дейвиса» (Аскаргалиева А., Алматы)

## Profile

PDF, 18 страниц, текстовый слой на страницах 1–8; страницы 9–18 — изображения и отзывы,
не заингещены. Коммерческая брошюра практикующего фасилитатора в Алматы. Ценность для проекта:
это **локальный казахстанский контекст** — та самая аудитория, для которой пишется Sulu Read,
и терминология, которой эта аудитория уже пользуется.

## Принято / Отклонено

**Принято:** перечень типовых ошибок при дисграфии («замена/пропуск букв/слогов,
потеря/добавление части букв») — это готовая спецификация того, какие искажения распознавание
речи и сравнение слов обязаны прощать. Отвлекаемость при СДВГ — обоснование размытия фона.

**Отклонено:** «каждого 20-го жителя планеты» — статистика без ссылки на источник,
в продукт не переносим. «Неспособность обучиться чтению» как определение дислексии —
формулировка жёстче, чем допускает продукт (Never Do #1). Пластилин — офлайн-инструмент.

## Fact-check

«По статистике, дислексия затрагивает каждого 20-го жителя планеты» — ссылки на исследование
в брошюре нет; не используем.
