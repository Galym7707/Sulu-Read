# Упражнения чтения Дейвиса: пошаговые процедуры

## Summary

Три упражнения из источника описаны достаточно точно, чтобы их можно было воспроизвести
в интерфейсе: Spell-Reading (назвать буквы по НАЗВАНИЯМ, затем услышать слово целиком),
Sweep-Sweep-Spell (быстрый повторный взгляд на слово, тренировка внутри ~200 мс) и
«Пунктуация в образах» (остановка на точке/запятой и проверка мысленного образа).
Ключевая деталь, которую легко потерять: в Spell-Reading запрещено произносить **звуки**
букв — только их названия.

## Implications

1. Эскалация подсказок в приложении обязана идти в порядке источника:
   быстрый повторный взгляд (Sweep) → произнесение по буквам (Spell) → слово целиком от
   «помощника» (TTS) → смысл. Порядок не наш, он взят из процедуры.
2. Уровень «по буквам» произносит **названия** букв («эм», «а»), а не звуки. Для TTS это
   означает, что нельзя просто скормить строку "м-а-м-а" — нужен явный список названий букв
   русского и казахского алфавитов. *(Допущение: источник описывает только русские/латинские
   буквы; названия казахских букв ә, ғ, қ, ң, ө, ұ, ү, һ, і берём из школьной казахской
   традиции и помечаем как проектное решение.)*
3. Уже существующий в Sulu Read слой слогов (`backend/app/services/syllabification.py`)
   в чистой процедуре Дейвиса отсутствует — Дейвис идёт от буквы. Но слоги прямо требует ТЗ
   заказчика. Решение: слоги — отдельная ступень **между** Sweep и Spell,
   и это помечено как расширение, а не как метод Дейвиса.
4. 200 мс — реализуемый параметр: длительность вспышки-подсказки при повторном показе слова.
   Это единственная цифра тайминга, которую источник даёт прямо.
5. Остановка на пунктуации даёт естественную границу «сцены» в режиме пословного чтения:
   после точки — вопрос «что ты увидел?», без обязательного текстового ответа.
6. Список искажений при дисграфии = спецификация допусков нечёткого сравнения: пропуск буквы,
   вставка буквы, замена буквы, пропуск слога. Distance по Левенштейну покрывает первые три,
   пропуск слога требует большего допуска на длинных словах.
