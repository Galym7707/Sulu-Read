# Доказательная база и цифры

## Summary

Единственное исследование во всём наборе источников — школьное исследование стратегий
Дейвиса на 86 учениках Сан-Франциско. Его ценность для проекта не в размере эффекта
(данные разработчика метода о собственном методе, конфликт интересов), а в **дизайне
измерения**: список из 100 коротких слов, порог точности 80%, сравнение с контрольной
группой. Этот дизайн можно перенести в приложение почти дословно. Остальные числа набора —
маркетинг.

## Implications

1. Метрика режима чтения в Sulu Read строится по образцу источника, а не по «ощущению
   прогресса»: фиксированный список слов, доля слов, произнесённых верно **без подсказки**,
   порог 80%. Список слов у приложения уже есть — слова, которые пользователь читал.
2. Порог 80% — это цифра источника, и её можно переносить как ориентир интерфейса
   («уровень освоен»), но нельзя переносить как обещание результата.
3. Числа «+4 класса за 5 дней», «пожизненный результат», «каждый 20-й житель планеты»
   в продукт не идут ни в каком виде — см. [[eticheskie-granicy-i-formulirovki|Этические границы]].
4. «Два часа дважды в неделю» и «40-60 часов» вместе дают ориентир: осмысленный горизонт —
   месяцы регулярной практики. UI должен показывать накопленную практику, а не только сессию.
   *(Проектное решение: в приложении уже есть `daily_wpm` и accuracy, к ним добавляется
   доля слов без подсказки.)*
5. Честная формулировка для продукта: у метода есть данные школьного пилота от его
   разработчиков; независимого подтверждения в предоставленных источниках нет. Приложение
   заявляет поддержку чтения и измеряет свой собственный эффект, а не наследует чужие цифры.
