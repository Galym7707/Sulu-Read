# Политика конфиденциальности Sulu-Read

Дата вступления в силу: 16 августа 2026 г.

Sulu-Read — приложение для помощи детям с дислексией в чтении на казахском,
русском и английском языках.

## Какие данные мы обрабатываем

**Звук с микрофона.** Когда ребёнок нажимает «Слушать» и читает вслух, запись
передаётся системе распознавания речи Android, чтобы проверить, правильно ли
прочитано слово. Приложение не хранит аудиозаписи и не передаёт их нам.

**Фотографии и файлы.** Если пользователь фотографирует страницу учебника или
загружает файл книги, изображение или файл отправляется на наш сервер, чтобы
распознать текст и разбить его на страницы. Файл обрабатывается и удаляется;
он не сохраняется на сервере после обработки.

**Текст для чтения.** Распознанный текст и отдельные слова отправляются на наш
сервер для упрощения текста и подсказок по значению слов.

**Профиль обучения.** Имя, выбранный язык и результаты упражнений хранятся,
чтобы приложение подбирало сложность заданий.

## Чего мы не делаем

- не показываем рекламу
- не передаём данные третьим лицам для маркетинга
- не собираем точное местоположение, контакты, список установленных приложений
- не требуем регистрации для чтения

## Разрешения

| Разрешение | Зачем |
|---|---|
| Микрофон | проверка чтения вслух |
| Камера | фотографирование страницы учебника |
| Доступ к файлам | загрузка файла книги, выбранного пользователем |
| Интернет | обработка текста на сервере |

Каждое разрешение запрашивается в момент использования и может быть отклонено:
приложение продолжит работать без соответствующей функции.

## Дети

Приложение предназначено для детей школьного возраста и используется под
присмотром родителей или учителей. Мы не собираем персональные данные детей
сверх перечисленного и не используем их для профилирования в рекламных целях.
