# Ответы для формы Data safety в Play Console

Заполняется в Play Console → App content → Data safety. Ниже — что отвечать,
исходя из того, что приложение реально делает.

## Собирает ли приложение данные? — ДА

### Аудио
- Тип: Voice or sound recordings
- Собирается: ДА | Передаётся третьим лицам: ДА (система распознавания речи Android)
- Цель: App functionality
- Обязательно: НЕТ (можно отказаться, есть кнопка самопроверки)
- Шифруется при передаче: ДА
- Можно запросить удаление: ДА

### Фото и видео
- Тип: Photos
- Собирается: ДА | Передаётся: НЕТ
- Цель: App functionality (распознавание текста со страницы)
- Обязательно: НЕТ
- Шифруется при передаче: ДА

### Файлы и документы
- Тип: Files and docs
- Собирается: ДА | Передаётся: НЕТ
- Цель: App functionality (чтение загруженной книги)
- Обязательно: НЕТ

### Личная информация
- Тип: Name (отображаемое имя профиля)
- Собирается: ДА | Передаётся: НЕТ
- Цель: App functionality, Personalisation
- Обязательно: НЕТ

### Действия в приложении
- Тип: Other in-app actions (результаты упражнений)
- Собирается: ДА | Передаётся: НЕТ
- Цель: App functionality, Personalisation

## Обработка
- Данные шифруются при передаче: ДА (HTTPS; HTTP отключён в релизной сборке)
- Пользователь может запросить удаление данных: ДА

## Реклама
- Приложение содержит рекламу: НЕТ
- Данные используются для рекламы: НЕТ

## Целевая аудитория
- Возраст: включает детей до 13 лет → применяется политика Families
- Требуется: политика конфиденциальности по публичному URL, возрастной рейтинг,
  отсутствие рекламных SDK
